Privacy Policy

FormPilot Vault helps users fill forms they opened themselves. The product is designed so the AI receives form structure, not raw personal profile values.

Data Stored Locally

The extension stores profile data, learned field mappings, usage counts, and license status in browser local storage. Profile values are encrypted at rest with device-local AES-GCM before they are stored. This data is used to prepare fill plans and improve repeated use on the same site.

Data Sent for AI Inference

Schema inference requests contain field metadata such as label text, placeholder, autocomplete hints, input type, nearby text, section title, required state, and select options. Raw names, addresses, phone numbers, emails, passwords, field values, cookies, authorization tokens, and CSS selectors are not sent.

Payments

Paid plans use Stripe Checkout. Card numbers and payment credentials are handled by Stripe. The service receives subscription and entitlement events needed to activate Plus, Pro, or Team access.

Safety Boundaries

  • The extension does not submit forms automatically.
  • The extension does not bypass CAPTCHA, SMS verification, or email verification.
  • The extension is not intended for mass account creation or activity that violates a website's terms.
