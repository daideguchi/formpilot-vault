Support

FormPilot Vault is a Chrome extension for user-confirmed form autofill.

How to get help

For bug reports, support requests, and product questions, please open an issue on the public GitHub repository.

Open a support issue

Before reporting

  • Do not include passwords, verification codes, payment card details, or other secrets.
  • Do not include full personal profile values unless they are dummy sample values.
  • Include the website type, field labels, and what should have been filled.

Safety boundary

FormPilot Vault fills fields only after user action. It does not submit forms, bypass CAPTCHA, bypass SMS or email verification, or create accounts in bulk.
