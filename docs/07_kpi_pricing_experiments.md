# KPIと価格実験

作成日: 2026-06-01

## まず見るKPI

| KPI | 意味 | 初期目標 |
|---|---|---:|
| scanned_fields | 収集できたフォーム項目数 | 8項目以上 |
| fillable_fields | 自動入力候補になった項目数 | 70%以上 |
| filled_fields | 実際に入力できた項目数 | 70%以上 |
| user_correction_rate | ユーザー修正率 | 30%未満 |
| time_saved_estimate | 推定削減時間 | 1フォーム60秒以上 |
| repeat_site_success | 2回目以降の成功率 | 90%以上 |
| free_limit_hit_rate | 月20回到達率 | 20%以上 |
| upgrade_click_rate | Upgradeクリック率 | 3%以上 |

## 価格実験

### 実験A: 低額Plus

- Plus: 580円/月
- Pro: 1,480円/月
- 狙い: 個人ユーザーの心理的負担を下げる

### 実験B: 仕事利用寄せ

- Plus: 980円/月
- Pro: 2,980円/月
- Team: 1,500円/人/月
- 狙い: フリーランス、営業、採用、バックオフィスへ寄せる

### 実験C: 買い切り初期回収

- Lifetime: 6,000-12,000円
- 狙い: 初期ユーザーとレビュー獲得
- 注意: 将来のクラウド同期やAIコストを含めない範囲に限定

## 課金に進む判断

次の2つを満たしたら課金導線を前面に出します。

1. 初回フォームで70%以上入力できる
2. Free利用者の20%以上が月20回に近づく

## 逆に止める判断

- 1フォームあたりの手間削減が30秒未満
- ユーザー修正率が50%超
- Chrome審査で権限やデータ説明が危険視される
- 個人情報をAIへ送る必要が出る
