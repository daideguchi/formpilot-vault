# 初期コンセプト固定

作成日: 2026-06-01
状態: `do_not_forget`

## 絶対に忘れない芯

この事業のゴールは、フォームを入力する人たちの細かな手間を、自動入力で解決することです。

ユーザーが困っているのは、AIを使いたいことそのものではありません。毎回同じようなフォームに、名前、住所、電話番号、メール、会社情報、カナ、郵便番号、生年月日などを入れる小さな面倒が積み重なることです。

この事業は、Playwrightで勝手に登録作業を完了するツールではありません。

`ユーザー本人が開いたフォームを、Chrome拡張が読み取り、AIが入力欄の意味を推定し、端末内プロフィールDBから対応する値を選び、content scriptで入力する補助ツール` です。

## 固定する設計

```text
ユーザーが登録フォームを開く
  -> Chrome拡張がDOMを収集
  -> AI/ルールがフォーム項目の意味を推定
  -> プロフィールDBのキーに対応づける
  -> ローカルで値を取得・整形
  -> content scriptで入力
  -> ユーザーが確認して送信
```

## やらないこと

- CAPTCHA回避
- SMS認証突破
- メール認証の自動突破
- 大量アカウント作成
- 規約違反を前提にした登録自動化
- 送信ボタンの無確認クリック
- 個人情報の実値をAIへ送ること

## Playwrightの位置づけ

Playwrightは本番B2C体験の入力実行ではなく、次の用途に使います。

- 自動テスト
- サンプルフォームの精度検証
- B2B版の半自動業務エージェント
- 大量フォームの回帰評価

## 価値の中心

価値は「住所と名前を自動入力できる」ではありません。

価値は、`個人情報Vaultと入力判断用RAG/記憶スペースを持ち、日本語を含む世界中のバラバラな新規登録フォームをAIが理解して、ほぼ完璧に埋める` ことです。

この事業の一番のコアは、フォーム入力する人の個人情報、会社情報、入力の癖、サイト別の正解、過去の修正をためて、次の入力判断に使えるデータベース/RAGを作ることです。

日本語フォームへの強さは差別化の入口です。ただし、事業としては日本語専用に閉じません。世界配信では、UI翻訳だけでなく、各国のフォームラベル、姓名順、住所分割、郵便番号、電話番号、生年月日、同意チェック、右書き言語、TLD、ページ言語を `locale_context` とサイト別Memoryに取り込みます。

特に強くする領域:

- 姓/名、セイ/メイ、カナ/ひらがな
- 郵便番号ハイフンあり/なし
- 住所一体型/分割型
- 都道府県select
- 生年月日select
- 会社名、部署、役職
- 不明項目だけユーザーに聞く体験
- サイト別学習
- 言語別/地域別のフォーム文脈
- 個人情報Vault
- 入力判断用RAG/記憶スペース
